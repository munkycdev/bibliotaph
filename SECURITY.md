# Security

Bibliotaph runs on your own machine, reads your files in place and never writes to them. If you find a way to make
it modify or delete a source file, leak a saved password or API key, or run code from a crafted PDF outside the
sandboxed PDF worker, please report it privately rather than in a public issue.

Report it through GitHub's private vulnerability reporting: the **Security** tab of this repository, then
**Report a vulnerability**. Include the version or commit, what you did and what happened.

Only the latest commit on `main` is supported while the project is pre-release.
