# Security

Bibliotaph runs on your own PC, reads your files in place and never writes to them. If you find a way to make it
modify or delete a source file, leak a remembered password, an AI key or an online-library sign-in, or run code from a
crafted PDF outside the sandboxed PDF worker, please report it privately rather than in a public issue.

Report it through GitHub's private vulnerability reporting: the **Security** tab of this repository, then
**Report a vulnerability**. Include the version (**Copy details** in **About Bibliotaph** copies it), what you did and
what happened. Please don't attach a book you bought or pages from one.

Fixes go into a new release, which installed copies download by themselves. Only the latest release is supported.
